# Prerequisites
- [**Node.js**](https://nodejs.org/en/download)
- [**pnpm**](https://pnpm.io/installation)
- [**Rust**](https://rust-lang.org/tools/install/)
- [**WebView2**](https://developer.microsoft.com/en-us/microsoft-edge/webview2/consumer?ch=1&form=MA13LH&cs=1277212064)
- [**Microsoft C++ (MSVC) Build Tools**](https://learn.microsoft.com/en-us/cpp/overview/acquire-msvc?view=msvc-170) (include "Desktop development with C++")

# Dev
After  cloning:
```bash
pnpm install
```

and run dev
```bash
pnpm tauri dev
```
